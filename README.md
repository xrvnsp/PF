## 🚀 Overview

This repository hosts the official personal portfolio and interactive showcase of **Saravana Prakash R**, an **XR & Spatial Computing Developer**. 

Built with a fusion of **Three.js, WebGL shaders, React 19, Vite, and GSAP**, the site delivers a cinematic cyberpunk aesthetic combined with buttery-smooth 60fps performance across desktop and mobile devices.

> *"Crafting immersive, high-fidelity spatial experiences at the intersection of virtual reality, real-time 3D, and modern web technologies."*

## ✨ Key Interactive Features

### 🌌 1. Three.js Interactive Particle Field & Shaders
- Dynamic, cursor-reactive particle universe that responds dynamically to mouse physics, clicks, and mobile touch events.
- Ambient camera parallax, neon depth glow, and intelligent render throttling when tabs are out of focus.

### 🪪 2. 3D Physics Identity Lanyards
- Real-time interactive 3D company ID badges and lanyards rendered via Three.js with realistic verlet constraint physics, drag mechanics, and double-sided GLTF badge textures.
- Highlights career milestones at **Avon Solutions**, **Madras Mindworks**, and **Digifox Studio**.

### 🤖 3. Procedural "Pico XR" Assistant Bot
- Floating interactive XR headset companion widget with procedurally animated visor eyes (blinking, saccadic eye movements, directional gaze, and cyan glowing shaders).
- Built-in contextual callouts, quick navigation prompts, and audio-visual feedback.

### 🕶️ 4. Interactive XR 3D Showcase (`xr-showcase.html`)
- Morphing point-cloud visualization featuring **Meta Quest 3** and **Apple Vision Pro** headsets.
- Interactive camera controls, orbit navigation, and particle transformation states powered by Three.js and GSAP.

### 📊 5. Real-Time Admin Telemetry & Analytics (`/admin`)
- Live visitor activity stream with real-time timestamps and simulated online presence.
- Geolocation insights, device telemetry, and automated inbound contact lead capture with local and cloud synchronization.

### ⚡ 6. Ultra-Fast Performance & SEO Optimization
- Sub-second cold loads powered by **Vite 5** and modern **WebP** image compression.
- Native lazy loading, responsive layout shifts (zero CLS), and complete **JSON-LD Schema (Person & ProfilePage)** structured data for maximum search indexing.

## ⚡ Quick Start & Local Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
- `npm` or `pnpm`

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/xrvnsp/PF.git
   cd PF
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

3. **Start the local Vite development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser to view the application with hot-module reloading.

4. **Build for production:**
   ```bash
   npm run build
   ```
   Compiles optimized production bundles and copies static assets into `dist/`.

5. **Preview production build locally:**
   ```bash
   npm run preview
   ```
